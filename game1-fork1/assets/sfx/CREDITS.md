# Звуки: источник и лицензия

Файлы `*.mp3` взяты без изменений из «Словохода» (`game_studio/game1/assets/audio/sfx/`, ветка `release/vk-full`, коммит `0a8abe3`). Там они собраны из паков Kenney скриптом `tools/process_audio.py`; полный список исходников — `game1/assets/audio/CREDITS.md`.

Все звуки — **CC0 1.0** (public domain, https://creativecommons.org/publicdomain/zero/1.0/), автор Kenney Vleugels (Kenney.nl): паки Music Jingles, Impact Sounds, RPG Audio, UI Audio, Interface Sounds.

| Файл | Событие в игре |
|---|---|
| `step.mp3` | буква добавлена в путь (высота растёт с номером буквы) |
| `found.mp3` | слово найдено |
| `wrong.mp3` | путь не составил ответ |
| `win.mp3` | история разгадана |
| `hint.mp3` | помощь |
| `tap.mp3` | нажатие кнопки |
| `reward.mp3` | находка легла в атлас |
| `chapter.mp3` | финал пробной главы |
